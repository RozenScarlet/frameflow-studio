# 首次发布验证

验证时间：2026-09-22。

- `npm run build` 通过。
- Chrome 验证创作页、模型配置保存、成片播放和下载入口。24 秒 DEMO 成片能够解码播放，1280 × 720，无媒体解码错误。
- 隔离的本地模拟服务验证 Responses 图文输入、视频关键帧输入，以及混合 reasoning/message 输出解析。
- 验证 H3 `t2va`、`fl2va` 首尾帧、`ref2va` 图片/视频/音频的提交、轮询和下载合同。
- 通用 HTTP 模板保留数字/数组类型，支持嵌套响应字段和自定义状态映射。
- 真实 FFmpeg 合成得到 12.021 秒、1280 × 720、H.264 视频和 AAC 双声道音轨的 MP4；独立 SRT 时间线正确。
- 验证失败保留其他成功镜头、任务取消、拒绝重复任务、密钥和授权头加密保存、不向客户端返回密钥，以及拒绝跨站写入。

边界：模型接口使用模拟服务，没有执行真实 H3 或 Responses 模型推理；没有测量模型质量、推理耗时或成本。ComfyUI 仍需用户实际工作流联调。本地测试数据、密钥、素材和演示视频未随源码发布。
